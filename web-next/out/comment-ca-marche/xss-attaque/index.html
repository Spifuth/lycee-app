# pour aller plus loin

  • · XSS = injection de code côté navigateur (≠ injection SQL qui touche la BDD).
  • · Trois familles : stockée (en base, persistante), reflétée (dans une URL), DOM-based (entièrement côté front).
  • · Parade moderne : Content Security Policy + framework qui encode par défaut (React, Vue, etc. — toujours échapper, jamais innerHTML).
